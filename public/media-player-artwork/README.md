# Media-player artwork

These local assets are decorative provider identifiers used when Home Assistant
does not return usable media artwork. They are kept local so the fallback does
not depend on a remote image request.

The SVG marks come from the Simple Icons distribution, with provider metadata
linking to official brand guidance where it is published. Amazon Music, Peacock,
BritBox, and LocalTV+ use first-party assets from their public sites. The PNG
icons for providers without a public downloadable kit are first-party site
icons.

Official references consulted:

- YouTube: <https://developers.google.com/youtube/terms/branding-guidelines>
- Netflix: <https://brand.netflix.com/en/assets/logos/>
- Plex: <https://www.plex.tv/about/privacy-legal/plex-trademarks-and-guidelines/>
- Apple TV: <https://tv.apple.com/>
- LocalTV+: <https://www.yourlocaltv.org/>
- Simple Icons source: <https://github.com/simple-icons/simple-icons>
